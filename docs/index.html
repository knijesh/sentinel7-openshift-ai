The premise · fictional scenario, synthetic data

A patrol vessel with no data centre on board.

RAG works where you have a data centre. At sea you don't, so the model itself has to know the job.

The organisation

Blue Defence

A fictional Singapore defence company. Its Sentinel-7 uncrewed surface vessels patrol the Singapore Strait, with watchkeepers on shore consoles.

The problem

Messy notes, strict reports

Operators send terse radio notes. The ops room needs each one turned into a strict JSON contact report (BD-SCR). No field invented, the operator's certainty kept, fault codes exactly as the vessel manual gives them.

s7 0612z patrol 6kn hdg 270 batt 64 vis gd. poss small craft brg 040
The constraints

Thin link, no GPU, sovereign data

  • LINK A thin satellite link: ship a 62 MB adapter, not a new model
  • CPU No GPU at sea: the model runs offline on a laptop
  • ACCESS Notes, manuals, data and models stay inside one access-controlled project

01

Granite 4.1-3B, tuned, beat 70B and 120B hosted models on exact reports, with a prompt 15× shorter.

Why OpenShift AI · three layers of value

You keep TRL, Unsloth and transformers. You stop building the glue around them.

Training Hub runs Unsloth, TRL and SentenceTransformers under the hood. The value sits on top: methods Red Hat built, one API across them, and a platform that runs, tracks, serves and governs the result.

Prerequisites · set up once per project
  1. 01
    Project access

    The cluster admin grants the training-edit role in your project, so notebooks can start training jobs on the cluster.

  2. 02
    A GPU size to pick

    A hardware profile for your GPU. About 10 GB of GPU memory (a share of one NVIDIA L4) is enough for LoRA on Granite 4.1-3B.

  3. 03
    Training Hub workbench image

    Training Hub, the Kubeflow SDK, MLflow and TRL come preinstalled. Choose it when you create the workbench.

  4. 04
    Project storage

    One volume for models, data and checkpoints, shared by the workbench and the training jobs.

  5. 05
    MLflow and pipelines

    Turn on MLflow tracking for the project, and add a pipeline server so you can run the promotion pipeline.
